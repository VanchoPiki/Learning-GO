Задача 1:
Моделирование Транзакции
Создай структуру Transaction со следующими полями:
From (строка — от кого)
To (строка — кому)
Amount (дробное число float64 — сколько)
Success (булево значение — прошла ли транзакция)
В main создай одну успешную транзакцию и выведи её на экран.

Задача 2:
Пополнение баланса (Работа с указателем на структуру)
Возьми структуру Wallet из урока:

type Wallet struct {
    Address string
    Balance float64
}

Напиши функцию deposit(w *Wallet, amount float64).
Если amount <= 0, функция должна напечатать "Ошибка: сумма пополнения должна быть больше 0" и ничего не менять.
Если сумма нормальная, прибавь amount к w.Balance и напиши "Баланс успешно пополнен".
В main создай кошелек с балансом 10.0, пополни его на 25.5 с помощью функции и распечатай итоговый баланс.

Задача 3:
Вложенность (Пользователь бота)
Создай структуру TelegramUser:
ID (int64)
Username (string)
Wallet (структура Wallet из Задачи 2)
В main создай пользователя и выведи сообщение вида:
"Юзер @alex с ID 123456 имеет баланс: 50.0 USDT".

Задача 4:
Срез структур (База кошельков)
Создай срез кошельков []Wallet, положи туда 3 разных кошелька с разным балансом.
Пройдись по срезу циклом for range и посчитай суммарный баланс всех кошельков.
Выведи общую сумму в консоль.
