В Go **нет классов**, как в Python, Java или C++. Вообще нет.
Вместо них используются **структуры**. Это основа всего: от создания модели пользователя в базе данных до парсинга крипто-транзакций.

---

# Урок: Структуры (`struct`) в Go

**Структура** — это твой собственный, кастомный тип данных, который объединяет несколько связанных по смыслу полей (переменных) под одним именем.

* Представь **паспорт**: в нем есть имя (`string`), возраст (`int`), и гражданство (`string`).
* В Go такой паспорт называется структурой.

---

## 1. Объявление и создание структуры

Синтаксис:
```go
type ИмяСтруктуры struct {
    Поле1 Тип
    Поле2 Тип
}
```

Давай создадим модель криптокошелька:

```go
package main

import "fmt"

// Создаем наш собственный тип "Wallet"
type Wallet struct {
    Address  string  // Адрес кошелька
    Balance  float64 // Баланс в монетах
    Currency string  // Валюта (BTC, ETH, TON)
    IsActive bool    // Активен ли кошелек
}

func main() {
    // Способ 1: Создание с именованными полями (САМЫЙ ЛУЧШИЙ И БЕЗОПАСНЫЙ)
    w1 := Wallet{
        Address:  "0x71C...3a9",
        Balance:  2.45,
        Currency: "ETH",
        IsActive: true, // Запятая в конце обязательна!
    }

    // Способ 2: Пустая структура (все поля заполнятся нулями / пустой строкой / false)
    var w2 Wallet
    w2.Address = "UQDt...11"
    w2.Currency = "TON"
    // w2.Balance останется 0.0, а w2.IsActive будет false

    fmt.Println(w1)
    fmt.Println(w2)
}
```

## 2. Доступ к полям через точку `.`

Чтобы прочитать значение или изменить его, используется обычная точка:

```go
func main() {
    w := Wallet{Address: "0x123", Balance: 10.0}

    // Читаем поле:
    fmt.Println("Баланс кошелька:", w.Balance) // 10.0

    // Меняем значение поля:
    w.Balance = 15.5
    fmt.Println("Новый баланс:", w.Balance)    // 15.5
}
```

## 3. Указатели на структуры (Связка с прошлым уроком!)

В 90% реальных проектов структуры передают **по указателю** (через `&` и `*`), чтобы не копировать их целиком и чтобы функции могли менять их поля.

И тут создатели Go сделали нам царский подарок: **автоматическое разыменование!**
Тебе **не нужно** писать уродливую конструкцию `(*w).Balance`. Go сам понимает, что ты обращаешься к полям структуры через указатель!

```go
package main

import "fmt"

type Wallet struct {
    Address string
    Balance float64
}

// Функция принимает УКАЗАТЕЛЬ на кошелек, чтобы изменить оригинальный баланс
func addMoney(w *Wallet, amount float64) {
    // Go сам понимает указатель! Пишем просто через точку:
    w.Balance += amount
}

func main() {
    myWallet := Wallet{Address: "0xABC", Balance: 100.0}

    // Передаем адрес структуры через &
    addMoney(&myWallet, 50.0)

    fmt.Println("Баланс после пополнения:", myWallet.Balance) // 150.0!
}
```

## 4. Вложенные структуры (Структура внутри структуры)

В реальной жизни объекты состоят из других объектов. Например, у **Пользователя Telegram** может быть свой **Кошелек**:

```go
package main

import "fmt"

type Wallet struct {
    Address string
    Balance float64
}

type User struct {
    TelegramID int64
    Username   string
    Wallet     Wallet // Вложенная структура!
}

func main() {
    user := User{
        TelegramID: 987654321,
        Username:   "crypto_whale",
        Wallet: Wallet{
            Address: "0xDEF...999",
            Balance: 500.0,
        },
    }

    // Добираемся до баланса через двойную точку:
    fmt.Printf("Пользователь @%s имеет баланс: %.2f\n",
        user.Username, user.Wallet.Balance)
}
```
