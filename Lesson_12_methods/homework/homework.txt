Задача 1:
Метод вывода профиля пользователя
Возьми структуру TGUser:

type TGUser struct {
    ID       int64
    Username string
    Balance  float64
}
Напиши для нее метод PrintProfile().
Он должен выводить: "Пользователь: @Username | Баланс: X USDT".
Подумай: какой ресивер выбрать (Value или Pointer)? Если мы ничего не меняем — лучше Value (u TGUser).

Задача 2:
Метод списания (Withdraw)
Добавь для TGUser метод Withdraw(amount float64) bool.
Какой ресивер нужен тут, если баланс уменьшается? Конечно, Pointer: (u *TGUser).
Если денег хватает — списываем и возвращаем true.
Если не хватает — пишем об ошибке и возвращаем false.

Задача 3 (Крутая!):
Метод перевода между юзерами (Transfer)
Напиши метод Transfer(to *TGUser, amount float64) bool.
Метод вызывается у одного юзера (from) и принимает указатель на другого юзера (to) и сумму.
Логика:
Проверяем, хватает ли денег у отправителя.
Если нет — возвращаем false.
Если да — списываем amount у отправителя и прибавляем amount к балансу получателя (to.Balance += amount).
Возвращаем true.
В main:
Создай пользователя @alice с балансом 100.0.
Создай пользователя @bob с балансом 10.0.
Вызови перевод: alice.Transfer(&bob, 40.0).
Вызови PrintProfile() у обоих и убедись, что у Алисы стало 60.0, а у Боба 50.0!
