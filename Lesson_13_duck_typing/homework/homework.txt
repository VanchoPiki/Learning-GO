Домашнее задание (Система уведомлений бота)
Представь, что в твоем сервисе происходит важное событие (например, пришел платеж по крипте), и тебе нужно отправить уведомление пользователю. Способы отправки могут быть разными.

Задача 1:
Интерфейс Notifier
Создай интерфейс:

type Notifier interface {
    Notify(message string)
}

Задача 2:
Две реализации
Создай структуру TelegramNotifier:
Поле Username string
Напиши для нее метод Notify(message string):
выводит в консоль: "[Telegram -> @Username]: <message>".
Создай структуру EmailNotifier:
Поле Email string
Напиши для нее метод Notify(message string):
выводит в консоль: "[Email -> <Email>]: <message>".

Задача 3:
Универсальная функция рассылки
Напиши функцию SendAlert(n Notifier, text string).
Внутри функции просто вызови метод Notify у переданного объекта n.
В main:
Создай одного TelegramNotifier (например, @crypto_man).
Создай одного EmailNotifier (например, man@crypto.com).
Вызови функцию SendAlert для обоих сервисов с текстом "Вам начислен 1 BTC!".

Задача 4:
Массовая рассылка через срез
В main создай срез уведомителей notifications := []Notifier{ ... }, положи туда и Telegram, и Email.
Пройдись по срезу циклом for range и отправь всем сообщение "Сервер уходит на техобслуживание!".
