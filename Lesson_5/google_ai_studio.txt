Двигаемся дальше! Функции в Go — это фундамент языка. В Go нет классов (как в
Java или C++), поэтому функции здесь правят бал.

В них есть пара крутых особенностей, которые выгодно отличают Go от других
языков (например, возврат сразу нескольких значений из одной функции).

Урок: Функции в Go (Базовый уровень)

Функция — это изолированный кусок кода, который принимает данные на вход, что-то
с ними делает и (опционально) возвращает результат.

Общий синтаксис функции выглядит так:

func имяФункции(параметр1 тип, параметр2 тип) типВозвращаемогоЗначения {
    // тело функции
    return результат
}

Важное отличие Go от C/Java: тип данных пишется после имени
переменной/параметра! Не int a, а a int. И тип возвращаемого значения пишется
после круглых скобок.

1. Простая функция и параметры

Если параметров несколько и они одного типа, их тип можно указать только один
раз в конце — через запятую.

package main

import "fmt"

// Функция принимает два параметра и ничего не возвращает
// Запись (name string, age int)
func printUserInfo(name string, age int) {
    fmt.Printf("Имя: %s, Возраст: %d\n", name, age)
}

// Фишка: сокращенная запись (a, b int) вместо (a int, b int)
func printSum(a, b int) {
    fmt.Println("Сумма:", a+b)
}

func main() {
    // Вызов функций:
    printUserInfo("Алексей", 25)
    printSum(10, 20)
}

2. Функция, которая возвращает значение (return)

Если функция должна вернуть результат, мы обязаны:

1.  Указать тип возвращаемого значения после круглых скобок.
2.  Использовать оператор return внутри функции.

package main

import "fmt"

// Функция принимает два float64 и возвращает одно число float64
func multiply(x, y float64) float64 {
    return x * y // Возвращаем результат умножения
}

func main() {
    // Сохраняем результат работы функции в переменную
    result := multiply(2.5, 4.0)
    fmt.Println("Результат:", result) // 10
}

3. Главная фишка Go: Возврат НЕСКОЛЬКИХ значений

В большинстве языков функция может вернуть только что-то одно (одно число, одну
строку или массив/объект). В Go функция может возвращать сразу 2, 3 и более
значений через запятую!

Для этого возвращаемые типы нужно обернуть в круглые скобки (тип1, тип2).

package main

import "fmt"

// Функция возвращает ДВА значения: результат деления и остаток
func divide(a, b int) (int, int) {
    quotient := a / b // Целая часть
    remainder := a % b // Остаток
    return quotient, remainder // Возвращаем оба через запятую!
}

func main() {
    // Принимаем оба значения в две разные переменные
    q, r := divide(10, 3)
    fmt.Printf("Частное: %d, Остаток: %d\n", q, r) // Частное: 3, Остаток: 1
}

На этой особенности в Go построена вся обработка ошибок (функции обычно
возвращают (результат, ошибка)).

4. Пустой идентификатор _ (пропуск ненужного)

В Go компилятор запрещает создавать переменные, которые ты потом не используешь.
Но что делать, если функция вернула два значения, а тебе нужно только одно?

Используй символ подчеркивания _. Он говорит Go: "Я знаю, что здесь есть
значение, но оно мне не нужно, просто выкинь его".

package main

import "fmt"

func getNameAndAge() (string, int) {
    return "Иван", 30
}

func main() {
    // Нам нужно только имя, а возраст не интересен:
    name, _ := getNameAndAge()

    fmt.Println("Привет,", name)
    // Переменной для возраста нет, ошибки компиляции тоже нет!
}
