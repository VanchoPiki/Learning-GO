Домашнее задание

Напиши решения для следующих 4 задач:

Задача 1:
Четные числа (Классический for)
Напиши цикл от 1 до 20 (включительно).
Выводи в консоль только четные числа.
Подсказка: используй if i%2 == 0.

Задача 2:
Банковский вклад (for как while)
У тебя есть начальный депозит deposit := 10000.0 (рублей).
Ты положил его в банк под 8% годовых (каждый год сумма увеличивается: deposit = deposit * 1.08).
Напиши цикл, который считает, через сколько лет депозит превысит 20000.0 рублей (удвоится).
Заведи счетчик лет years := 0 и увеличивай его на каждой итерации. Выведи итоговое количество лет в консоль.

Задача 3:
Пропуск кратных чисел (continue)
Напиши цикл, который идет от 1 до 15.
Если число делится на 3 без остатка (i % 3 == 0), пропусти его с помощью continue.
Все остальные числа выведи на экран.
(В выводе должны отсутствовать: 3, 6, 9, 12, 15).

Задача 4:
Найти число (for бесконечный + break)
Начни с числа num := 1.
Запусти бесконечный цикл for { ... }.
На каждом шаге увеличивай num++.
Найди первое число, которое одновременно делится и на 7, и на 11 (то есть num%7 == 0 && num%11 == 0).
Как только нашел — выведи его на экран и прерви цикл с помощью break.
