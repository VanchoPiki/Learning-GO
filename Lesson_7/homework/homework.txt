Задача 1:

Базовые манипуляции
Создай массив строк cities из 4 городов (например: "Москва", "Париж", "Токио", "Берлин").
Выведи длину массива с помощью функции len().
Замени первый город на любой другой.
Выведи в консоль первый и последний элемент массива.


Задача 2:
Сумма и среднее арифметическое (Цикл range)
Создай массив дробных чисел prices := [...]float64{120.5, 45.0, 310.2, 89.9, 15.4}.
С помощью цикла for range посчитай:
Общую сумму всех цен.
Среднюю цену (сумма / количество элементов).
Выведи оба значения в консоль (для среднего сделай округление до 2 знаков: %.2f).


Задача 3:
Поиск максимума в массиве
Создай массив чисел numbers := [...]int{23, -5, 42, 18, 99, 3, 77}.
Найди максимальное число в этом массиве и его индекс.
Подсказка: создай две переменные maxNum := numbers[0] и maxIndex := 0, затем пройдись циклом по массиву и сравнивай каждый элемент с maxNum.
Выведи результат: "Максимальное число: X на позиции Y".


Задача 4:
Проверка независимости копии
Напиши функцию changeFirst(arr [3]int). Внутри функции измени первый элемент: arr[0] = 999.
В main создай массив myArr := [3]int{1, 2, 3}.
Вызови функцию changeFirst(myArr).
Распечатай myArr в main. Что произошло и почему? Напиши краткий ответ в комментарии к коду.
