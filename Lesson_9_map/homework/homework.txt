Задача 1:
Телефонная книга (Базовые операции)
Создай карту phonebook, где ключ — имя (string), а значение — номер телефона (string).
Добавь трех человек: "Мама", "Друг", "Работа".
Измени номер телефона для "Друг".
Удали "Работа" с помощью функции delete.
Выведи всю телефонную книгу на экран.

Задача 2:
Проверка доступа (comma-ok)
Создай карту прав доступа пользователей:

permissions := map[string]bool{
    "alex":  true,
    "john":  false,
    "guest": false,
}

Напиши проверку для пользователя "maria":
Используй конструкцию if value, ok := ...
Если пользователя нет в карте — выведи "Пользователь не найден".
Если есть и значение true — выведи "Доступ разрешен".
Если есть, но значение false — выведи "Доступ запрещен".
Поменяй имя с "maria" на "alex" и проверь, что теперь пишет "Доступ разрешен".

Задача 3:
Подсчет стоимости корзины (Итерация range)
Есть карта цен продуктов:

cart := map[string]float64{
    "Хлеб":    40.0,
    "Молоко":  85.5,
    "Сыр":     240.0,
    "Шоколад": 95.0,
}

С помощью цикла for key, value := range cart подсчитай общую стоимость всей корзины.
Выведи в консоль список всех товаров и в самом конце — общую сумму: "Итого к оплате: X руб.".

Задача 4 (со звездочкой ⭐):
Счетчик символов
Есть строка: text := "golang" (или любая другая строка).
Создай пустую карту charCounts := make(map[rune]int) (символы строки в Go имеют тип rune при переборе).
Пройдись по строке с помощью цикла for _, char := range text и подсчитай, сколько раз встречается каждый символ.
Подсказка: charCounts[char]++ автоматически увеличивает счетчик (если ключа не было, Go вернет 0, прибавит 1 и запишет в карту!).
Распечатай итоговую карту (для красивого вывода символов вместо чисел-кодов используй в цикле %c: fmt.Printf("%c: %d\n", char, count)).
