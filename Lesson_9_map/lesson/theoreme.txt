# Урок: Карты в Go (`map`)

**Карта (`map`)** — это неупорядоченная коллекция пар **«ключ — значение»** (`key-value`).

* **Аналогия:** Записная книжка с телефонами. Ключ — это имя человека (оно уникально), а значение — его номер телефона. Зная имя, ты мгновенно находишь номер.
* Поиск по ключу в карте происходит **молниеносно**, сколько бы элементов там ни лежало (сложность O(1)).

---

## 1. Создание карт

Синтаксис типа: `map[ТипКлюча]ТипЗначения`

### Вариант 1: Через функцию `make()` (Рекомендуемый способ)
```go
// Создаем пустую карту, где ключ - строка, а значение - число
ages := make(map[string]int)
```

### Вариант 2: Литерал карты (сразу с данными)
```go
prices := map[string]float64{
    "Хлеб":   45.5,
    "Молоко": 89.9,
    "Кофе":   250.0, // Запятая в конце обязательна!
}
```

### ⚠️ Опасная ловушка: `nil`-карта
Если просто объявить переменную через `var`, карта будет равна `nil`:
```go
var myMap map[string]int

// Читать из нее можно:
fmt.Println(myMap["test"]) // Выведет 0

// НО ПИСАТЬ В НЕЕ НЕЛЬЗЯ:
// myMap["test"] = 10 // ПАНИКА! (panic: assignment to entry in nil map)
```
> **Правило:** Всегда инициализируй карты через `make(...)` или фигурные скобки `{}` перед записью!

## 2. Базовые операции: Запись, Чтение, Удаление

```go
package main

import "fmt"

func main() {
    users := make(map[string]string)

    // 1. Добавление и Перезапись (синтаксис одинаковый)
    users["admin"] = "Алексей"
    users["guest"] = "Иван"
    users["guest"] = "Дмитрий" // Перезаписали значение для ключа "guest"

    // 2. Чтение
    fmt.Println("Админ:", users["admin"]) // Алексей

    // 3. Чтение НЕСУЩЕСТВУЮЩЕГО ключа
    // Go НЕ падает с ошибкой, а возвращает НУЛЕВОЕ значение типа (для string это "")
    fmt.Println("Модератор:", users["moderator"]) // Выведет пустоту ""

    // 4. Удаление через функцию delete(карта, ключ)
    delete(users, "guest")
    fmt.Println("После удаления:", users) // map[admin:Алексей]

    // Удаление несуществующего ключа ошибки НЕ вызывает:
    delete(users, "some_ghost") // Безопасно, ничего не произойдет
}
```

## 3. Проверка: Есть ли ключ в карте? (Идиома `comma-ok`)

Раз при чтении несуществующего ключа Go возвращает дефолтный `0` или `""`, возникает проблема:
> *Если `scores["Иван"]` вернул `0`, значит ли это, что Иван набрал 0 очков, или Ивана вообще нет в списке?*

Чтобы отличить эти ситуации, используют знакомую нам идиому **`, ok`**:

```go
package main

import "fmt"

func main() {
    scores := map[string]int{
        "Иван": 0, // Иван есть, но набрал 0
    }

    // Карта при чтении возвращает ДВА значения: (значение, был_ли_ключ)
    score, ok := scores["Иван"]
    fmt.Printf("Очки: %d, Найден: %t\n", score, ok) // Очки: 0, Найден: true

    score, ok = scores["Петр"]
    fmt.Printf("Очки: %d, Найден: %t\n", score, ok) // Очки: 0, Найден: false

    // Красивая идиоматичная проверка через if с инициализацией:
    if val, ok := scores["Петр"]; ok {
        fmt.Println("Петр набрал:", val)
    } else {
        fmt.Println("Студент Петр не найден!")
    }
}
```

## 4. Обход карты циклом `range`

Карту можно перебирать обычным циклом `for range`. На каждом шаге он возвращает **ключ** и **значение**:

```go
package main

import "fmt"

func main() {
    fruits := map[string]int{
        "Яблоки": 10,
        "Груши":  5,
        "Сливы":  20,
    }

    for key, value := range fruits {
        fmt.Printf("Фрукт: %s, Количество: %d\n", key, value)
    }
}
```

> **Странная фишка Go (Важно!):**
> Карты в Go **не имеют порядка**! Если ты запустишь цикл `range` несколько раз подряд, элементы могут выводиться в **случайном порядке**. Создатели языка намеренно сделали порядок случайным, чтобы программисты не полагались на очередность элементов в словарях.
