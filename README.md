# Golang Roadmap

Репозиторий для отслеживания прогресса изучения языка Go: от базового синтаксиса до создания backend-приложений.

---

## 🟢 Этап 1: Синтаксический фундамент

- [x] Переменные и константы (`var`, `:=`, `const`)
- [x] Базовые типы данных (`int`, `float64`, `string`, `bool`)
- [x] Преобразование типов (Type casting)
- [x] Условные конструкции (`if`, `else if`, `else`, `switch`)
- [x] **Функции (Базовый уровень)** 📍 *(Текущая тема)*
- [ ] Циклы (`for` — классический, как `while`, бесконечный)

---

## 🟡 Этап 2: Коллекции данных

- [ ] Массивы (Arrays)
- [ ] Срезы (Slices) — `append`, `make`, емкость (`cap`) и длина (`len`)
- [ ] Итерация по коллекциям через `for range`
- [ ] Карты / Словари (Maps)
- [ ] Строки под капотом: байты и руны (`rune`)

---

## 🟠 Этап 3: Структурирование кода (ООП в стиле Go)

- [ ] Указатели (Pointers) — адресация (`&`) и разыменование (`*`)
- [ ] Структуры (Structs) — моделирование данных
- [ ] Методы структур
- [ ] Интерфейсы (Interfaces) — неявная реализация ("Duck typing")
- [ ] Композиция и встраивание вместо наследования

---

## 🔴 Этап 4: Обработка ошибок и стандартная библиотека

- [ ] Концепция явных ошибок (тип `error`, `errors.New`, `fmt.Errorf`)
- [ ] Управление потоком: `defer`, `panic`, `recover`
- [ ] Пакеты и модули (`go mod`, видимость функций через заглавные буквы)
- [ ] Полезные стандартные пакеты: `fmt`, `strings`, `strconv`, `time`, `os`

---

## 🟣 Этап 5: Конкурентность (Многопоточность)

- [ ] Горутины (Goroutines) — запуск через `go`
- [ ] Каналы (Channels) — буферизированные и небуферизированные
- [ ] Конструкция `select` для работы с каналами
- [ ] Синхронизация: `sync.WaitGroup` и `sync.Mutex`
- [ ] Пакет `context` (отмена операций, таймауты)

---

## 🔵 Этап 6: Практика и Backend

- [ ] Работа с форматом JSON (`encoding/json`)
- [ ] HTTP-сервер на базе стандартного пакета `net/http`
- [ ] Взаимодействие с базой данных (PostgreSQL / `database/sql`)
- [ ] Тестирование: написание Unit-тестов с помощью пакета `testing`
- [ ] Создание полноценного REST API проекта

---
